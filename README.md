# FishVenture API Service

RESTful API-сервис для игрового проекта FishVenture. Построен на **FastAPI** с использованием **PostgreSQL** и **SQLAlchemy**. Включает систему аутентификации, управление пользователями и игровую логику.

## Технологии
- Python 3.11+
- FastAPI
- PostgreSQL
- SQLAlchemy (ORM)
- Pytest (тестирование)
- Docker
- GitHub Actions (CI/CD)

## Основные возможности
- Регистрация и аутентификация пользователей (JWT)
- CRUD-операции для игровых сущностей
- Валидация данных через Pydantic
- Обработка ошибок и логирование
- Модульные и интеграционные тесты
- Контейнеризация и автоматический деплой
